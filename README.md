# 요즘테스트 — 트렌드 심리테스트·밸런스게임 모음

2026년 8월 실제 유행 데이터(메타센싱 트렌드, "장시간비행" 밈, "MBTI 바뀐 듯" 밈, 밸런스게임 포맷)를 근거로 제작한 퀴즈 4종을 담은 바이럴형 웹사이트입니다. Node.js/Express로 제작했고, 결과 공유 링크마다 서버에서 Open Graph 태그를 다르게 렌더링해서 카카오톡/인스타그램 등에 공유될 때 "나의 결과는 OOO형!" 형태로 보이도록 설계했습니다 — 이게 바이럴 확산의 핵심 장치입니다.

## 포함된 테스트

1. **나의 메타센싱 유형 테스트** (`/q/meta-sensing`) — 2026년 Z세대 메가트렌드 "메타센싱"(감정 인지·조절 능력) 기반
2. **장시간비행 여행 성향 테스트** (`/q/long-flight`) — SNS 화제 밈 "장시간비행" 기반
3. **요즘 내 성향, 예전이랑 같을까?** (`/q/vibe-shift`) — "나 MBTI 바뀐 듯" 트렌드에서 착안한 자체 유형 테스트 (공식 MBTI 아님, 상표권 문제 없도록 독자 유형명 사용)
4. **인생 밸런스게임 20선** (`/q/balance-game`) — 스테디셀러 포맷인 밸런스게임

## 1. 로컬에서 실행하기

```bash
npm install
npm start
```

`http://localhost:3000` 접속. API 키가 전혀 필요 없어 설치 후 바로 작동합니다.

## 2. 새 퀴즈 추가하는 방법

`data/quizzes.js` 배열에 객체 하나만 추가하면 홈 화면·라우팅에 자동으로 반영됩니다. 새로운 밈/트렌드가 뜰 때마다 이 파일에 항목을 추가하고 배포만 다시 하면 되는 구조라, "포트폴리오 전략"(트렌드 뜰 때마다 빠르게 추가)에 맞게 설계했습니다. 각 퀴즈는 `questions`(질문+선택지, 선택지마다 `type` 태그)와 `results`(유형별 제목·설명·공유문구)로 구성됩니다. 채점 방식은 단순 다수결(가장 많이 나온 type이 결과)입니다.

## 3. Render로 배포하기

기존 사이트들과 동일한 방식입니다.

1. 이 프로젝트 폴더를 GitHub 저장소에 올립니다.
2. Render 대시보드에서 **New > Web Service**로 저장소 연결.
3. Build Command: `npm install`, Start Command: `npm start`.
4. 배포 후 발급받은 실제 도메인을 `views/render.js` 상단의 `SITE_URL` 환경변수(`SITE_URL`)로 설정하세요. **이건 결과 공유 링크의 og:url이 정확한 도메인을 가리키게 하는 데 중요합니다** — 설정 안 하면 카카오톡 공유 미리보기가 깨질 수 있습니다. Render 환경변수에 `SITE_URL=https://실제도메인` 형태로 추가하면 됩니다.

## 4. 애드센스 연동

각 페이지의 `<div class="ad-placeholder">` 자리에 광고 코드를 넣으면 됩니다. 퀴즈 진행 화면(질문-선택지) 동안에는 광고를 배치하지 않았습니다 — 클릭 실수를 막고 완료율을 높이기 위한 의도적 설계입니다. 홈 화면과 결과 화면에만 광고가 있습니다.

## 5. 트래픽 전략 메모 (근거: 프로젝트 문서 `신규-바이럴형-웹사이트-아이디어-리서치.md`)

- 이 사이트의 승부처는 SEO가 아니라 카카오톡/인스타/스레드 등을 통한 결과 공유 확산입니다. 결과 페이지의 og:title이 "나의 결과는 OOO형!"처럼 뜨는 게 핵심이라, 배포 후 반드시 카카오톡으로 실제 링크를 보내서 미리보기가 제대로 뜨는지 확인하세요.
- 트렌드가 살아있는 동안(밈이 화제인 짧은 기간) 트래픽이 몰리는 경향이 있으므로, 새 밈이 뜨는 걸 포착하면 최대한 빠르게(하루~이틀) 새 퀴즈를 추가해서 배포하는 게 유리합니다.
- 하나의 퀴즈가 안 터져도 손실이 크지 않은 구조이므로, 여러 개를 계속 시도하는 포트폴리오 접근을 권장합니다.
