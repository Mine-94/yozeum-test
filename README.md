# 요즘테스트 — 사주팔자·오늘의 운세·심리테스트 모음 (한국판)

원래는 SNS 공유 노림형 심리테스트·밸런스게임 4종만 있는 사이트였지만, **"한국 vs 일본 우선순위 재검증" 결과**에 따라 사주팔자 계산기·오늘의 띠별 운세·띠 궁합 3개 도구를 추가해 "사주·운세" + "트렌드 테스트" 2섹션 구성으로 확장했습니다.

## 0. 읽기 전에 — 이번 확장의 판단 근거

프로젝트 문서 `한국-vs-일본-시장-비교-검증.md`, `한국-마케팅-어필리에이트-리서치.md`의 조사 결과에 기반합니다. **좋은 소식만이 아니라 안 좋은 소식도 그대로 적습니다.**

- **좋은 소식**: 한국 사주/운세/MBTI 붐은 2026년 8월 현재 검증된 현재진행형 트렌드입니다(한국일보 매일 코너, 이디야·바나나프레소 브랜드 캠페인, 서울 사주박람회, AI 사주 앱 "플롯" 첫 달 18만 리포트). 니치 경쟁 구조도 일본(shindanmaker·LINE占い 등 압도적 강자 과점)보다 훨씬 유리합니다 — 한국 사주 사이트는 비슷한 규모의 소형 사이트가 다수 난립하는 파편화된 시장입니다. 애드센스 정책상 사주/운세 콘텐츠 제한도 없습니다.
- **안 좋은 소식(정직하게)**: 일본판(しんだんラボ)에서 확인했던 것 같은 "건당 8,000~15,000엔" 규모의 명확한 제휴(어필리에이트) 프로그램은 한국에서 조사 결과 **하나도 확인하지 못했습니다.** 점신·포스텔러·헬로우봇·운세박사 모두 외부 사이트에 커미션을 주기보다 자체 오퍼월/ASO로 직접 유저를 사는 모델이 우세해 보입니다. 또한 그래스루트 마케팅 채널(네이버카페·디시인사이드·에펨코리아·틱톡·스레드·카톡오픈채팅 등) 대부분에서 "이 채널로 실제 트래픽을 얻었다"는 구체적 증거를 찾지 못했습니다 — "증거 없음"으로 분류된 채널이 압도적으로 많았다는 것 자체가 이번 조사의 핵심 발견입니다.
- **방침**: 애드센스를 기본 수익원으로 하고, 제휴는 점신 등에 직접 문의해 비공개 프로그램 여부를 확인하는 것을 다음 과제로 남겨둡니다. 마케팅은 확실한 근거가 있는 것만 우선 실행 — (1) 결과 페이지의 카카오톡 공유 버튼(실측 사례 있음), (2) 밈 유행에 빠르게 편승하는 실행 속도("테토-에겐" 트렌드가 개인 블로그→인스타툰→유튜브 쇼츠로 3년에 걸쳐 확산된 선례 참고). 나머지 채널은 소량 테스트 후 직접 효과를 측정하는 접근이 필요합니다.

## 1. 사이트 구성

### 사주·운세 (신규 추가, 실계산 로직)
- **정식 사주팔자 계산기** (`/saju`) — `lunar-javascript`(6tail) 라이브러리로 절기(입춘) 경계를 정확히 반영해 년·월·일·시주 전체를 계산. 오행 분포, 일간(日干) 기준 성격 해설 포함. 일본판은 절입시각 데이터 부재로 연주만 간이 계산했지만, 이 라이브러리는 절기 경계까지 정확히 처리하므로 정식 4주 계산이 가능합니다.
- **오늘의 띠별 운세** (`/unse`) — 날짜(KST 기준) + 띠를 시드로 매일 자동으로 바뀌는 총운·애정운·금전운·건강운. 재방문을 유도하는 핵심 콘텐츠입니다.
- **띠 궁합** (`/gunghap`) — 삼합(三合)·육합(六合)·충(沖) 등 명리학의 실제 지지(地支) 관계 이론으로 궁합을 계산합니다(임의로 만든 매트릭스가 아닙니다).

### 트렌드 테스트 (기존, 선택식 퀴즈)
- 나의 메타센싱 유형 테스트 / 장시간비행 여행 성향 테스트 / 요즘 내 성향 체크 / 인생 밸런스게임 20선 (`/q/:id`)

## 2. 계산 방법과 한계 (정직한 안내)

- **사주팔자**: `lunar-javascript` 라이브러리로 양력→음력 변환 및 절기(입춘 등) 경계를 반영해 년·월·일·시주를 계산합니다. 태어난 시각을 모르면 시주 없이 년·월·일주만 계산합니다(시주 계산에 정오를 더미값으로 사용하되 화면에는 표시하지 않음 — 일주 경계와 먼 시각이라 안전합니다). 오행 해설은 8자(또는 시간 미상 시 6자)의 오행 분포를 세는 간이 방식이며, 실제 정통 사주 해석은 십성·용신·격국 등 훨씬 복잡한 요소를 함께 봐야 합니다.
- **띠**: 사주학 정통 기준인 **입춘(2월 4일 무렵)**을 년의 경계로 사용합니다. 음력설이나 양력 1월 1일 기준으로 알려진 띠와 1~2월생의 경우 다를 수 있다는 점을 결과 페이지에 명시했습니다. (검증: 2023년 사례로 `bazi.getYearZhi()`가 입춘 당일 정확히 바뀌는 것을 확인했고, 반대로 라이브러리의 `getYearShengXiao()`는 음력설 기준으로 바뀌는 것도 확인 — 두 기준이 다르다는 걸 인지하고 사주학 기준으로 일관되게 선택했습니다.)
- **띠 궁합**: 삼합/육합/충 3종은 명리학에서 가장 표준적이고 이견이 적은 지지 관계 이론입니다(12지지를 원형으로 배치했을 때의 기하학적 구조로도 교차검증됨). 원진살 등 유파차이가 큰 개념은 제외했습니다.
- **오늘의 운세**: 날짜+띠+카테고리를 시드로 한 고정 문구 풀에서 매일 다른 문구를 보여주는 방식입니다(포털 사이트의 일반적인 오늘의 운세 콘텐츠와 동일한 방식). 실제 운세를 예측·보장하지 않는다는 점을 결과 페이지에 명시했습니다.

## 4. 새 퀴즈/도구를 추가하는 방법

- 트렌드 테스트 추가: `data/quizzes.js` 배열에 객체 하나 추가.
- 사주/운세 도구를 홈 카드에 추가: `data/fortune-tools.js`에 추가.
- 일간/오행/띠 성격 문구 수정: `data/fortune-content.js`.
- 오늘의 운세 문구 추가: `data/fortune-content.js`의 `DAILY_FORTUNE_POOL`에 카테고리별로 추가.

## 5. Render로 배포하기

1. 이 프로젝트 폴더를 GitHub 저장소에 올립니다.
2. Render 대시보드에서 **New > Web Service**로 저장소 연결.
3. Build Command: `npm install`, Start Command: `npm start`.
4. 배포 후 발급받은 실제 도메인을 `SITE_URL` 환경변수로 설정하세요. Render 환경변수에 `SITE_URL=https://실제도메인` 형태로 추가하면 됩니다. **og:url·트위터카드·사이트맵·robots.txt 전부 이 값을 사용하므로 필수입니다.**
5. (선택·권장) 네이버 서치어드바이저에서 사이트 등록 후 "HTML 태그" 방식으로 발급되는 `content` 값을 `NAVER_SITE_VERIFICATION` 환경변수로 설정하면 소유 확인 태그가 자동으로 출력됩니다.

## 6. SEO 관련

- `/sitemap.xml`·`/robots.txt`는 서버가 `SITE_URL`을 이용해 자동 생성합니다(정적 파일이 아니므로 수동 편집 불필요).
- **2026년 8월 SEO 보강**: sitemap에 `/unse/:animal`(12개), `/gunghap/r/:my/:partner`(12×12=144개 순서쌍), 신규 `/ilgan/:stemKey`(10개, 아래 참고) 동적 페이지를 모두 추가했습니다. 이전에는 정적 경로만 sitemap에 있어서 이미 만들어져 있던 동적 결과 페이지들이 크롤러에 노출되지 않고 있었습니다.
- **신규: 일간(日干) 단독 랜딩 페이지** (`/ilgan/갑=gap, 을=eul, 병=byeong, 정=jeong, 무=mu, 기=gi, 경=gyeong, 신=sin, 임=im, 계=gye`) — 생년월일 계산 없이 "갑목 성격"처럼 일간 하나만 검색하는 수요를 노리는 10개의 정적 랜딩 페이지입니다. `/saju` 폼과 상호 링크되어 있습니다.
- `/unse`(오늘의 띠별 운세) 페이지 제목/설명을 "8월21일 오늘의 띠별 운세"처럼 실제 검색 패턴에 맞춰 날짜를 맨 앞에 노출하도록 수정했습니다(한국-SEO-키워드-리서치 문서의 제안 반영).
- `/saju`, `/gunghap` 폼 화면에 관련 결과 페이지로 가는 내부 링크 그리드를 추가했습니다(크롤러 발견성 + 재방문 유도).
- 모든 페이지에 `canonical` 태그를 설정했습니다.
- 사주팔자/오늘의 운세/띠 궁합 결과 페이지는 선택식 퀴즈보다 긴 설명을 넣어 SEO 콘텐츠 두께를 확보했습니다.
- 네이버 서치어드바이저 소유확인용 `<meta name="naver-site-verification">` 태그를 환경변수 `NAVER_SITE_VERIFICATION` 설정 시 자동 출력하도록 했습니다(미설정 시 출력 안 함).

## 7. 광고(애드센스 등) 연동

각 페이지의 `<div class="ad-placeholder">`에 광고 코드를 넣으면 됩니다. 퀴즈 진행 화면과 사주/궁합 입력 폼 화면에는 광고를 배치하지 않았습니다 — 완료율을 높이기 위한 의도적 설계입니다. 사주/운세 장르는 애드센스 정책상 제한 카테고리가 아님을 확인했습니다(공식 정책 문서 기준). 다만 "100% 적중" 같은 단정적 문구는 콘텐츠 정책상 지양해야 합니다.

## 8. 수익화 관련 메모 (리서치 근거: `한국-마케팅-어필리에이트-리서치.md`)

- 조사 시점 기준 한국에는 일본의 電話占いヴェルニ 같은 명확한 제휴(어필리에이트) 프로그램을 확인하지 못했습니다. 점신(1,900만 사용자, 매출 830억원)에 "제휴 문의" 채널로 직접 연락해 비공개 프로그램 여부를 확인하는 것이 다음 액션입니다.
- 그래스루트 마케팅 채널 중 근거가 있는 것은 (1) 카카오톡 공유 버튼(W컨셉 심리테스트 실측 사례 있음, 단 최우선 채널은 아니었음), (2) 밈 유행 즉시 편승 전략("테토-에겐" 선례) 정도입니다. 나머지는 검증되지 않았으므로 소량 테스트 후 직접 효과를 측정해야 합니다.

## 9. 트래픽 전략 메모

- 결과 공유 링크가 카카오톡/인스타그램 등에 공유될 때 og:title이 "OOO띠, 오늘의 운세" "나의 사주 일간은 OOO!" 형태로 뜨도록 설계했습니다 — 배포 후 반드시 실제 링크를 카카오톡으로 보내 미리보기가 제대로 뜨는지 확인하세요.
- 오늘의 띠별 운세는 매일 콘텐츠가 바뀌는 재방문 유도 장치입니다 — 이 사이트에서 가장 먼저 "지속 방문형" 목표에 부합하는 기능입니다.
- 새 밈/트렌드 감지 시 최대한 빠르게(하루~이틀) `data/quizzes.js`에 새 퀴즈를 추가해서 배포하는 게 유리합니다(기존 전략 유지).

## 10. 오늘의 운세가 매일 정확히 한국 자정에 바뀌는 이유

Render 등 클라우드 서버는 보통 UTC로 동작합니다. `lib/fortune.js`의 `getTodayKST()`가 서버 시각에 KST(UTC+9)를 명시적으로 더해 "오늘" 날짜를 계산하므로, UTC 자정(=한국시간 오전 9시)이 아니라 한국시간 자정에 운세가 바뀝니다.

## 11. 오늘의 검토 사항

- 오늘의 운세 문구 풀이 카테고리별 16개로, 장기적으로는 반복이 눈에 띌 수 있어 문구를 주기적으로 추가하는 것을 권장합니다.

- 인기 이름/생년 조합의 프로그래매틱 SEO 페이지 사전 생성 여부는 사주 URL 조합이 검색어와 직접 대응되지 않아 우선순위 낮음(성명판단이 아닌 사주라 검색 매칭 가치가 낮음).

- MBTI×띠 콤보 콘텐츠(경쟁자가 적은 블루오션으로 조사됨) — 아직 미착수.
